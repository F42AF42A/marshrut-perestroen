# Маршрут перестроен

Браузерный автомобильный раннер: заснеженная дорога, туман, скользкие повороты и олени. Основной формат — вертикальный экран телефона; поддерживаются клавиши ← / → и касания левой / правой половины экрана.

## Запуск локально

Нужен Python 3. Из корня репозитория:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Сборка и установка npm-пакетов не требуются. JavaScript использует ES-модули, поэтому открывать index.html непосредственно через file:// не следует.

## Исходники

- `dist/index.html`, `dist/style.css` — интерфейс.
- `dist/game.js` — сцена, управление, физика и счётчик расстояния.
- `dist/chaser.js` — автомобиль.
- `dist/deer.js` — модель оленя.
- `dist/wildlife.js` — переходы оленей и вороны.
- `dist/roadside.js` — события на 5 и 6 км, пар дыхания и выхлоп.
- `dist/drone.js` — синтез музыки, реверберация и стереодилей.
- `dist/three.module.js` — локальная копия Three.js r170 (MIT).

Папка `dist` содержит редактируемые исходники статического сайта, а не результат сборки. Аудио запускается после взаимодействия с пользователем, согласно ограничениям браузера.
