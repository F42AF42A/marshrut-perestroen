# Работа над «Маршрут перестроен»

- Пользователь попросил перенести весь проект в свой GitHub и отправлять последующие изменения туда сразу после проверки. При подтверждённом подключении используйте этот GitHub-репозиторий как основное место хранения исходников.
- Не заявляйте, что изменения отправлены в GitHub, пока push не завершился успешно. Пока GitHub remote не настроен, перенос не завершён: сначала подключите аккаунт и получите настоящий URL репозитория; не придумывайте владельца или URL.
- Сохраняйте историю Git. Не используйте force push и не перезаписывайте существующий чужой репозиторий.
- Проект статический, ES-модули находятся в dist/. Для локального запуска достаточно HTTP-сервера; npm-сборка не нужна.
- После правок выполняйте подходящую проверку синтаксиса и необходимую проверку поведения, затем коммитьте и отправляйте изменения в подключённый GitHub.
- Не добавляйте токены, временные архивы, скриншоты из upload/ и локальные проверки в репозиторий.
- Адрес опубликованной игры и .openai/hosting.json сохраняйте. GitHub push и публикация в Sites — отдельные операции; соблюдайте действующий процесс Sites при изменении игры.

- Пользователь явно выбрал публичный GitHub-репозиторий marshrut-perestroen. После подключения создавайте публичный репозиторий.
- Игра открыта всем по ссылке: сохраняйте публичный доступ при следующих публикациях и используйте обычный, а не private, путь Sites.
